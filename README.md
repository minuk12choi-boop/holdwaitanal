# holdwaitanal — Fab Flow Monitor

반도체 Fab 내 Line별 생산 흐름과 진행 제약을 비교·진단하는 PC 전용 웹페이지 프로젝트.

이 저장소는 **작업 지시와 결과 보고를 주고받는 채널**로 사용한다.

---

## 저장소 사용 규칙

```
WORK/ORDERS/     ← 작업지시서를 놓는 곳 (입력)
WORK/REPORTS/    ← 작업완료결과서를 놓는 곳 (출력)
STATUS.md        ← 현재 진행 현황 / 남은 일 / 우려 / 에러  (항상 최신 유지)
docs/            ← 설계서 및 참조 문서
```

### 작업 지시 (ORDERS)

- 파일명: `YYYY-MM-DD_O###_제목.md`
- 예: `2026-08-04_O001_FlowStack_구현.md`
- 지시서를 올린 뒤에는 `STATUS.md`의 `대기 중인 결정` 항목을 확인할 것.

### 결과 보고 (REPORTS)

- 파일명: `YYYY-MM-DD_R###_제목.md`
- 각 결과서는 다음을 반드시 포함한다.
  - 완료한 일
  - 남은 일
  - 다음에 해야 할 일
  - 우려되는 일
  - 에러 / 막힌 지점
  - 결정이 필요한 질문

### 진행 현황 (STATUS.md)

작업이 끝날 때마다 갱신한다. 이 파일만 보면 현재 상태를 알 수 있어야 한다.

## 데이터 자산

| 파일 | 내용 |
|---|---|
| `x.txt` | Oracle → Impala 테이블 매핑 (9개) 및 Impala 컬럼 사전 |
| `xx.txt` | 원본 Oracle 쿼리 — 현재 시점 WIP 스냅샷 (KFR4 / PFR1 / KFR7) |

## 원칙

설계서 §25-24에 따라 **실제 데이터 산식과 테이블 매핑은 임의로 추정하지 않는다.**
확인이 필요한 항목은 구현을 멈추지 말고 Mock으로 진행하되, `STATUS.md`에 질문으로 남긴다.
