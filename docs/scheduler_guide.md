# Windows 작업 스케줄러 설정 가이드

**등록할 작업은 하나뿐이다.** `run_build_f3.bat` 이 22시대 실행에서
`get_move.py` 까지 이어서 돌린다.

---

## 0. 준비

`git pull` 후 아래 파일이 있는지 확인한다.

```
D:\PERSONAL_SPACE\SW\python\7_holdwaitanal\scripts\run_build_f3.bat
```

탐색기에서 안 보이면 "보기 → 파일 확장명" 을 켠다.
**먼저 더블클릭해서 정상 동작하는지 확인**한다. 창이 바로 닫히면
`logs\build_f3.log` 를 열어 오류를 본다.

테이블이 아직 없다면 한 번만 손으로 만든다.

```
python getdata\db_common.py --init
```

## 1. 작업 만들기

작업 스케줄러 → 오른쪽 **작업 만들기** (기본 작업 만들기 아님)

### 일반
- 이름: `holdwaitanal_build_f3`
- **사용자가 로그온했는지 여부에 관계없이 실행**
- **가장 높은 수준의 권한으로 실행** 체크

### 트리거 → 새로 만들기
- 작업 시작: `일정에 따라` → `매일`
- 시작: **오늘 날짜**, 시간 **`22:00:00`**
- 고급 설정
  - `작업 반복 간격` 체크 → **`2시간`**
  - `기간` → **`1일`**

22:00 시작 + 2시간 간격이면 22, 00, 02 ... 20 으로 떨어져
**shift 기준시각 06 / 14 / 22 에 모두 정확히 걸린다.**
오늘 밤 22시부터 바로 적재가 시작된다.

### 동작 → 새로 만들기
- 동작: `프로그램 시작`
- 프로그램/스크립트:
  `D:\PERSONAL_SPACE\SW\python\7_holdwaitanal\scripts\run_build_f3.bat`
- **시작 위치(옵션)**: `D:\PERSONAL_SPACE\SW\python\7_holdwaitanal`

시작 위치를 비우면 `C:\Windows\System32` 에서 실행돼 `.env` 를 못 찾는다.
(래퍼가 `cd /d "%~dp0.."` 로 보정하지만 함께 지정해 두는 것이 안전하다.)

### 설정
- `작업이 이미 실행 중이면` → **`새 인스턴스 시작 안 함`**
- `작업이 실패하는 경우 다시 시작 간격` → `10분`, `3회`

## 2. get_move 를 왜 따로 등록하지 않는가

| | build_f3 | get_move |
|---|---|---|
| 필요 주기 | 2시간 (실시간 화면 + shift 누적) | 1일 1회 |
| 실행 시점 | 짝수 정각 | 업무일이 끝나는 22:00 직후 |

주기가 달라 처음에는 작업을 둘로 나눴지만, **get_move 가 필요한 시점이
build_f3 의 22시 실행 직후와 정확히 겹친다.** 그래서 래퍼에서 시각을 보고
22시대일 때만 이어 돌린다.

```bat
for /f %%h in ('powershell -NoProfile -Command "(Get-Date).Hour"') do set HH=%%h
if "%HH%"=="22" ( python getdata\get_move.py )
```

build_f3 가 3~4분 걸리므로 get_move 는 22:04 쯤 시작한다. get_move 는
해당 업무일 구간을 지우고 다시 넣는 **교체 적재**라 여러 번 돌아도 결과가 같다.

수동으로 돌리고 싶을 때만 단독 래퍼를 쓴다.

```
scripts\run_get_move.bat            수동 재적재
scripts\run_get_move.bat --full     3개월치 백필
```

## 3. db_common.py 는 등록하지 않는다

실행 진입점이 없는 공용 라이브러리다. 테이블 생성 때만 `--init` 으로 한 번 쓴다.

## 4. 확인

| 확인 대상 | 방법 |
|---|---|
| 실행 여부 | 작업 스케줄러 → `마지막 실행 결과` 가 `0x0` |
| 로그 | `logs\build_f3.log`, `logs\get_move.log` |
| 적재 여부 | 웹 `/api/health/` 행수 |
| 스냅샷 이력 | 웹 `다운로드` 페이지 |

`0x1` 이면 파이썬 오류다. 로그 마지막 부분을 본다.
