# 작업지시서 (ORDERS)

이 폴더에 작업지시서를 올려주세요.

## 파일명 규칙

```
YYYY-MM-DD_O###_제목.md
```

예: `2026-08-04_O001_FlowStack_구현.md`

## 권장 양식

```markdown
# O001 — 제목

## 목적
무엇을 위한 작업인지.

## 범위
- 포함:
- 제외:

## 상세 요구사항
1.
2.

## 완료 기준
- [ ]
- [ ]

## 참조
- docs/blueprint_fab_flow_monitor.md §N
```

## 확인 사항

지시서를 올리기 전에 `STATUS.md`의 **4번 대기 중인 결정** 항목을 확인해주세요.
해당 항목이 미해결이면 지시받은 작업이 도중에 막힐 수 있습니다.
